    どの記事がどう動いている？

    棒はすべての記事で同じ物差し（対数目盛）です。縦の点線は全記事の中央値です。右端の数字は前回の記録からの増加です。

    全体の中でどんな位置？

    未返信のコメント

    自分の記事についたコメントのうち、あなたがまだ返信していないものです（noteの「作者が返信済みか」の情報を使っています）。返信すると、この画面を開いたときや、記事のページで30秒ほど待つと自動で消えます。返信したあと、noteでもう一度「Ponで記録」をタップすると消えます。返信しないと決めたものは「対応済み」にできます。

    返信への返信（要確認）

    あなたが返信したコメントに、相手からさらに返信が来たものです。noteの通知から拾っているため、直近2〜3週間分と、それ以降に届いたものが対象です。すでに返信していたら「確認済み」にしてください。

    自分がコメントした記事

    他の人の記事を開いたときにコメント欄から見つけたものと、通知（あなたのコメントへの返信・スキ）から見つけたものを記録しています。noteには自分のコメント一覧の機能がないため、拡張機能を入れる前のコメントは、その記事を開き直すか、返信・スキの通知が来たときに追加されます。

    称号

    画面の上、名前の前に表示されます。海賊・海軍・海の住人の肩書から選ぶか、「自由に名乗る」で好きな肩書を入れてください（16文字まで）。

    着せ替え

    グラフの色（インプレッション＝青、PV＝橙、スキ＝緑）は、どの着せ替えでも同じです。パソコンやスマホの「ダークモード」に合わせて、暗い配色にも切り替わります。

    特別な称号

    作者ジァン=サマー（@jeanjeanjean）の記事にスキ・コメント・引用をすると増えます。引用は、Ponに記録した自分の記事の本文に、彼の記事のURL（埋め込み）があるかで判定します。

      「記録」と「ダウンロード」の違い

      note→ Ponに記録このブラウザの中→ ⬇ ダウンロードパソコンのファイル

      記録は、Ponがグラフや一覧を表示するために、このブラウザの中にデータを貯めておくことです。ファイルとしては見えません。
      ⬇ ダウンロードのボタンを押すと、パソコンの「ダウンロード」フォルダにファイル（CSVなど）が保存され、Excelなどで開けます。

      記録する

      noteにログインした状態で note.com を開き、ブックマークレット「Ponで記録」をタップします。記録が終わると自動でこの画面に戻り、データが追加されます。

      ブックマークレットの登録方法

      スマホでは自動では記録されません。毎日1回タップすると、日ごとの増え方がきれいに記録されます。本文の保存はパソコン版Pon（Chrome拡張機能）でできます。

      noteから記録する

      noteのタブが開いていない場合は、noteのトップページを裏で開いて記録し、終わったら自動で閉じます。noteへのアクセスは1秒以上の間隔をあけて行います。

      記事の本文をダウンロード

      ボタンを押すと、Ponにまだ記録していない記事の本文をnoteから取り込んでから、全記事分のファイルをパソコンにダウンロードします。初回は1記事1秒以上の間隔をあけるため、約200記事で4分ほどかかります（その間はこの画面を開いたままにしてください）。2回目からは、新しい記事の分だけ取り込むのですぐに終わります。

      Web版では本文をnoteから取り込めません。パソコン版Pon（Chrome拡張機能）のバックアップを読み込むと、ここからダウンロードできます。

      くわしい設定・説明

      CSVの列は GAS版の「記事一覧」シートと同じ順（A:URL / B:タイトル / C:本文 / D:日付）で、後ろに文字数・ハッシュタグ・有料/無料などが続きます。本文が3万文字を超える記事は「本文(続き2)」以降の列に分けています（Excelの1セルの上限対策）。1記事だけ欲しいときは、「記事」タブの各記事にある「⬇ 本文をダウンロード」を押してください。

      数値のダウンロード・バックアップ

      バックアップ

      Ponに記録したデータは、このブラウザの中にだけあります。拡張機能を削除すると消えるので、ブラウザの「Cookieとサイトデータ」を削除すると消え、機種変更でも引き継がれないので、ときどきバックアップファイルをダウンロードしておいてください。パソコン版とWeb版のバックアップは互いに読み込めます。
