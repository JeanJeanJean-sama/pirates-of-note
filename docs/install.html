Ponで記録 登録のしかた

Web版 Pirates of note（非公式）

しくみ

スマホのブラウザでは拡張機能が使えないため、ブックマークレット（ブックマークに登録する小さなプログラム）で記録します。

  1. noteにログインした状態で note.com を開く
  2. ブックマークの「Ponで記録」をタップ（数秒〜数十秒）
  3. 自動で Web版Pon に切り替わり、データが追加される

登録するのは短いコードで、実行するたびに、このサイトからPonのプログラム本体を読み込んで動きます。コードには本体の「指紋」が入っていて、登録したときと中身が1文字でも違う本体は、ブラウザが実行しません。そのため、あとからサイトが書き換えられても、あなたのnoteで知らないプログラムが動くことはありません。Ponの記録の仕組みが新しくなったときは、Web版Ponの画面でお知らせするので、このページからコードを登録し直してください。

取得するのは自分のアカウントのデータだけです。データはあなたのブラウザの中にだけ保存され、外部のサーバーには送りません（受け渡しに使うURLの「#」より後ろは、サーバーに送られない仕組みです）。noteへのアクセスは1秒以上の間隔をあけて行います。

① ブックマークレットのコード

下の「コードをコピー」を押してください。次の手順で、ブックマークのURLとして貼り付けます。

外部から読み込まない版（パソコン向け）

プログラム全体をブックマークに入れる長い版です。このサイトから読み込まずに動きます。記録の仕組みが新しくなったときは、同じように登録し直してください。スマホ（特にAndroid）では長すぎて途中で切れ、動かないことがあります。

② ブックマークに登録

  1. このページを開いたまま、Chromeの右上の ⋮ → ☆（ブックマークに追加）をタップします。
  2. 画面下に出る「編集」をタップします（見逃したら ⋮ → ブックマーク → 追加したブックマークの ⋮ → 編集）。
  3. 名前を「Ponで記録」に変えます。
  4. URLの欄を長押しして全部消し、①でコピーしたコードを貼り付けて保存します。
  5. 使うとき：noteのページで、アドレスバーに「Ponで記録」と入力し、候補に出る☆マークの「Ponで記録」をタップします。
    ※候補の一番上に出る検索ではなく、☆のついたブックマークを選んでください。
  1. このページを開いたまま、Safariの下にある 共有ボタン（□に↑）をタップし、「ブックマークを追加」を選んで保存します。
  2. 下の 本のアイコン（ブックマーク）をタップし、右下の「編集」を押して、いま追加したブックマークをタップします。
  3. 名前を「Ponで記録」に変えます。
  4. アドレスの欄の ⓧ を押して消し、①でコピーしたコードを貼り付けて「完了」を押します。
  5. 使うとき：noteのページで、本のアイコン → 「Ponで記録」をタップします。
  6. このWeb版Ponを「ホーム画面に追加」してください（共有ボタン → ホーム画面に追加）。iPhoneのSafariは、7日間開かないサイトのデータを消すことがありますが、ホーム画面に追加すると対象外になります。
  1. ブックマークバーを表示します（Chromeなら Ctrl+Shift+B、Macは ⌘+Shift+B）。
  2. 下のボタンを、ブックマークバーにドラッグします。
    ⚓ Ponで記録
  3. 使うとき：noteのページで、ブックマークバーの「Ponで記録」をクリックします。
  4. Chromeをお使いなら、自動で毎日記録できる拡張機能版がおすすめです。

③ 使いかたのコツ

  • 1日1回タップすると、日ごとの増え方がきれいに記録されます（自動では記録されません）。
  • 初回はコメントの確認に数分かかります。急ぐときは「コメント確認を後回し」を押してください。2回目からは数秒〜数十秒です。
  • 未返信コメントは、noteで返信したあと、もう一度「Ponで記録」をタップすると一覧から消えます。
  • データはこのブラウザの中にだけあります。ときどき「データ・設定」→「バックアップを共有」で、Googleドライブなどに保存してください。機種変更のときは、新しいスマホで「バックアップから復元」します。
