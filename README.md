# Pirates of note（Pon） v0.6.2 — β版

自分のnoteのアクセス数値を記録・分析する**非公式**ツールです。

noteのアクセス数値を毎日自動で記録し、推移を見える化するChrome拡張機能です。取得するのは**自分のアカウントのデータだけ**です。
未返信のコメントや、自分が他の人の記事に書いたコメントも記録します。

> note株式会社とは関係のない非公式ツールです。noteの仕様が変わると動かなくなることがあります。

## できること（無料版）

| 機能 | 内容 |
|---|---|
| 毎日の自動記録 | noteを開いたときに1日1回、全記事の**全期間の累計**（インプレッション・PV・スキ・コメント・売上）とフォロワー数を記録 |
| 記録の確定 | 記録した日の数字を、次の日以降に noteの「その日の終わり」の数字に直す（前の日の統計を読む。本人の統計のみ）。日ごとの増えた数が、記録した時刻に左右されない。記録のない日は作らない。設定で OFF にできる |
| 累計 | 概要のいちばん上に「累計（これまでの合計）」として、最後の記録の日時と、前回比が何日前の記録と比べた数字かを表示 |
| 推移グラフ | 前回の記録から増えた数と累計を、指標ごとに表示（使い始めた日から記録がたまる） |
| 期間の動き | 7日・28日・月ごと（カレンダーの月）・カスタム・前回の記録からの期間で、インプレッション・PV・スキ・コメント・フォロワーの増えた数と公開本数を、前の期間と比べて表示（増減率つき）。← → でさかのぼれる。日ごとの動きは線グラフ（前の期間を点線で重ねる）と棒グラフを切り替え。棒グラフは指標ごとの段（入口＝インプレッション・PV、反応＝PV・スキ・コメント）に分け、段ごとの最大値を基準に表示し、下に率の数字の段。カーソルを合わせる（スマホはタップ）と、その指標の数字だけを表示 |
| 率 | 開封率（PV÷インプレッション）・スキ率（スキ÷PV）・コメント率（コメント÷PV）を、累計と選んだ期間で表示。前の期間との差はポイントで表示 |
| 伸びた記事・期間ごとの比較 | 選んだ期間で伸びた記事の上位10。同じ長さの期間を最大8つ並べて、全体の合計と記事ごとに比べる。記録のない日があれば知らせる |
| 共有用に出す | noteの振り返り記事に使う文字（箇条書き）と画像（PNG）を作り、📋 コピーまたは ⬇ ダウンロード |
| 記事カード | 記事ごとに「入口（IMP→PV）」「反応（PV→スキ）」を棒で比較。全記事の中央値の目印、前回比、開封率・スキ率。見出し画像と、累計の線グラフ・増えた数の棒グラフ（日ごと・月ごと）。「推移を大きく見る」で1記事ずつ大きく表示 |
| 記事を探す | 記録した本文・タイトル・ハッシュタグ・投稿日で探し、記事カードへ移動 |
| カレンダー | 投稿した日を自動で表示。投稿予定（特定の日か期間）・コンテスト（開始日〜終了日）・その他の予定を手で入れて、近い締切・予定を画面に表示（通知は使わない）。4種類を色と印（●○⚑◆）で見分ける |
| セルフミッション | 連続投稿日数・期間内の投稿本数・フォロワー数・累計PV・累計スキ数の目標を決めて、進み具合を記録から自動で表示 |
| マップ | 全記事を散布図（両対数）で表示。A：IMP→PV、B：PV→スキ。直近30日の記事を色分け。補助線は「斜めの線（開封率・スキ率の目安）」と「4つの区画」（中央値で区切り、区画ごとの本数を表示。インプレッションが少ない記事は除く）を選べる |
| 記事一覧（表） | 並べ替えと絞り込みができる表。前回比、開封率（PV÷IMP）、スキ率（スキ÷PV）つき |
| 未返信コメント | 自分の記事についたコメントのうち、まだ返信していないものを一覧表示。未返信の件数はアイコンに数字で表示。「対応済み」にもできる |
| 返信への返信 | 自分の記事のコメントのやり取りで、自分が返信したあとに相手がまた書き込んだもの（要確認）。やり取りの返信の一覧を読んで判定し、最後に自分が返信すれば自動で消える |
| 自分のコメントへの返信 | 他の人の記事に書いた自分のコメントに返信が来たもの（未確認）。通知から見つけ、「確認済み」を押すか、最後に自分が返信すると消える。アイコンの数字に入れるかを選べる |
| 自分がコメントした記事 | 他の人の記事を開いたときにコメント欄から、また通知（自分のコメントへの返信・スキ）から記録 |
| 本文の保存 | 自分の記事の本文を保存してCSVを自動でダウンロード（直近7日の新しい記事は自動、それ以前はボタンでまとめて）。CSV（GAS版の記事一覧シートと同じ列順）とMarkdown（ZIP）で書き出し |
| 本文を選んでダウンロード | すべて・今月・先月・投稿日の範囲・記事ごとに選んで、CSV／Markdown を1つのファイルか記事ごとのZIPで ⬇ ダウンロード |
| 書き出し | 最新データまたは全記録をCSVで書き出し。JSONでバックアップと復元（本文・予定・ミッション・設定も含む） |
| 表示する機能 | 使わない機能を画面から隠せる（データは消えない） |
| 設定の一覧 | 「設定」のタブの先頭に、すべての設定を1か所に並べる。その場の切り替えの横の「設定で見る」から移動できる |
| 使い始めの案内 | 記録を始めた日と、機能ごとに「あと◯日たまると使えます」を表示。初めて開いたときだけ4枚の使い方の説明 |
| 色 | グラフ・マップ・共有用の画像・カレンダーの色を1か所で選べる（元の色に戻す・見えにくい色の注意つき） |
| β版からの特典 | 2026年9月30日までに記録を始めていた人に、称号「初航海の乗組員」と名前の横の印（🧭）。フォローしていなくても使える。判定はブラウザの中で、記録の日付から自動で行う |
| 記録するアカウント | 1つのブラウザで複数のnoteアカウントを使っても記録が混ざらないよう、決めたアカウント以外でログインしているときは何も記録しない。混ざった記録を見つけて外すこともできる |

## スマホ・Web版（Pon Web）

スマホや、Chrome以外のブラウザでも使えるWeb版です。インストール不要で、ブックマークレット「Ponで記録」で記録します。

- **Web版を開く**：https://jeanjeanjean-sama.github.io/pirates-of-note/
- **登録のしかた**：https://jeanjeanjean-sama.github.io/pirates-of-note/install.html

データはそのブラウザの中にだけ保存され、外部には送りません。拡張機能版とWeb版のバックアップ（JSON）は、互いに読み込めます。

## インストール（β版）

1. ZIPを展開し、中の `pirates-of-note` フォルダを消さない場所に保存します。
2. Chromeで `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押して、このフォルダを選びます。
4. noteにログインした状態で `https://note.com/` を開きます。数十秒後に最初の記録が保存されます。
5. ツールバーのアイコンを押すと、ダッシュボードが開きます。

## 用語の一覧（画面の言葉はこれに合わせる）

| 使う言葉 | 意味・使い方 | 使わない言葉 |
|---|---|---|
| インプレッション | 記事が表示された回数。狭い所でも略さず、小さい文字にする | IMP、表示回数 |
| PV（ページビュー） | 記事が開かれた回数 | |
| 開封率 | PV÷インプレッション。説明の所だけ「CTR」を添えてよい | CTR（見出し・ボタン） |
| スキ率・コメント率 | スキ÷PV、コメント÷PV | |
| 記録 | Ponの中（このブラウザの中）に貯めること。「記録中」「記録待ち」「最後の記録」 | 保存（Ponの中に貯めることを指すとき） |
| 毎日の記録 | 1日1回の、全記事の数字の記録 | スナップショット |
| ⬇ ダウンロード | パソコンにファイルを作ること（CSV・バックアップ・画像） | 保存（ボタン名） |
| バックアップ／復元 | 記録をファイルにする／ファイルから記録に戻す | |
| 記録するアカウント | Ponが記録する noteのアカウント（1つのブラウザで1つ） | |
| 要確認 | 自分も書き込んだやり取りで、最後の書き込みが自分以外のもの | |
- ボタン名に「保存」は使わない。ファイルがパソコンに置かれたことを伝える文（「ダウンロード」フォルダに保存されています）や、ブラウザのブックマークの操作の説明は、そのままでよい。
- 利用者の目に触れない所（コードのコメント・内部のエラー名）は合わせなくてよい。

## 仕組みと安全性

- noteとの通信は、**noteのページ内（content script）でだけ**行います。
- 認証には、noteがブラウザに用意するCookie `note_gql_auth_token` を使います。拡張機能が自分で発行したり、保存したり、外部に送ったりすることはありません。
- noteへのリクエストは**1秒以上の間隔**をあけて送ります。
- 取得するタイミング
  - 全期間の記録：1日1回
  - 前の日の記録の確定：記録のたびに、まだ確定していない過去の記録の日を最大30日分（1日あたり 記事数÷100回の問い合わせ）。noteの集計が次の日に進むまで待つ
  - 通知の1ページ目：noteのページを開いたとき・移ったとき（開いたままのときも）、前に読んでから5分以上たっていれば1回（間隔は設定で 5分・15分・30分・1時間）。自分の記事へのコメントや自分のコメントへの返信が来ていたら、その記事のコメントだけを確かめます
  - 未返信コメントの確認：6時間ごと。記事一覧を読み直して、コメント数が変わった記事だけを確認します（読み直した数字は毎日の記録には使いません）
  - 通知の確認（全体）：12時間ごと
  - コメントに気づけるのは note を開いたときです（noteを開いていないときは何もしません）
- 保存先は、このブラウザの拡張機能用の保存領域（IndexedDB）だけです。外部のサーバーには何も送りません。
- 記録の前に、ログイン中のアカウントが「記録するアカウント」と同じか確かめます（`/api/v2/current_user`）。noteのログインの印が前と同じなら24時間は前の結果を使うので、問い合わせは1日に数回までです。ログインの印そのものは保存せず、見分けるための指紋（SHA-256）だけをブラウザ内に記録します。
- 「設定」の「noteから記録する」で、通信を伴う機能（自動の記録・コメントの確認・自分のコメントの記録・本文の取り込み・称号の確認）をそれぞれOFFにでき、OFFにした機能の通信は行いません。
- 使う権限は `unlimitedStorage`（ブラウザ内の保存領域の容量制限をなくす）と `https://note.com/*` の2つだけです。

## noteの利用規約について・運営の皆さまへ

Pon は、note の書き手が **自分自身のデータ** をふり返るために作った、個人による非公式ツールです。note株式会社とは関係がなく、公式の許可を得たものでもありません。note に迷惑をかけないよう、次のことを守っています。

- 取得するのは、ログインしている本人のデータと、誰でも見られる公開情報だけです。他人の非公開データは取得しません。
- ログインが必要な画面の制限を回避したり、有料記事を本来の方法以外で読んだりすることはしません。
- note へのリクエストは1秒以上の間隔をあけ、1日1回を基本にしています。
- 取得したデータは利用者のブラウザ内にだけ保存し、開発者を含む外部には送りません。
- 広告は表示せず、取得したデータを販売・分析・第三者提供に使うことはありません。

利用者の皆さまも、note の[利用規約](https://note.com/terms)を守ってお使いください。

**note株式会社の皆さまへ**：本ツールについて、仕様の変更・機能の停止・公開の停止などのご要望があれば、速やかに対応します。[Issues](https://github.com/jeanjeanjean-sama/pirates-of-note/issues) またはメール（remmusnaej@gmail.com）でご連絡ください。

## 使っている note の内部API（非公式）

| 用途 | API |
|---|---|
| 記事別の全期間の数値 | `POST https://graphql.note.com/graphql`（`dashboardNoteListConnection`, unit=ALL。date を過去の日にすると、その日の終わり時点の累計。記録の確定に使う） |
| 自分のID・フォロワー数 | `GET /api/v2/current_user`（ID・表示名・フォロワー数以外は保存しません） |
| コメント一覧・返信済みかどうか | `GET /api/v3/notes/{key}/note_comments`（`is_creator_replied`。公開情報のため、ダッシュボードからの再確認はログイン情報なしで行う） |
| コメントのやり取りの返信 | `GET /api/v3/notes/{key}/note_comments?parent_key={親コメント}&order=oldest`（返信への返信も含めて古い順。自分の記事と、自分がコメントした公開の記事だけ） |
| 通知 | `GET /api/v3/notices`（ふだんは1ページ目だけ。12時間ごとに最大25ページ、約300件。種類 `note_comment`・`note_comment_reply`・`note_comment_like` を使う。既読にはしない） |
| 記事の本文 | `GET /api/v3/notes/{key}`（noteのページ内・ログイン状態で取得） |
| フォロー特典の確認 | `GET /api/v2/creators/jeanjeanjean`（`isFollowing`）、`GET /api/v2/creators/jeanjeanjean/contents`（`isLiked`）、彼の記事の `note_comments` |

## 既知の制限

- 記録はアカウントごとに分けて持っていません。記録するアカウントを変えると、今までの記録と同じ場所に入ります（アカウントごとに分けて見る機能は今後の予定）。

- 無料版は「全期間の累計」を毎日記録し、その差から日ごとの増えた数を出します。記録しなかった日があると、その区間は数日分がまとめて1点になります。
- 自分のコメントのうち、拡張機能を入れる前に書いたものは、その記事を開き直すか、返信・スキの通知が届いたときに追加されます。
- 「今すぐ取得」でnoteのタブを裏で開いたときは、Chromeの省電力機能で処理が遅くなることがあります。
